# Предсказание цен на автомобили BMW (Kaggle BMW Pricing Challenge)

Научно-исследовательская работа, выполненная в рамках обучения в РТУ МИРЭА, Институт искусственного интеллекта.

## 📋 Содержание работы

Работа состоит из шести задач, направленных на получение навыков в области анализа данных и машинного обучения:

1. **Вычисление математического ожидания, дисперсии и СКО** — первичный статистический анализ данных (датасет `swiss`), построение моделей парной линейной регрессии.

2. **Множественная регрессия** — построение и улучшение модели множественной линейной регрессии, проверка мультиколлинеарности (датасет `Seatbelts`).

3. **Демографическое исследование** — выявление факторов, влияющих на заработную плату, работа с дамми-переменными и нормализацией.

4. **Классификация** — решение задачи бинарной классификации (определение пола ученика) с использованием Decision Tree и Random Forest, подбор гиперпараметров через GridSearchCV.

5. **Предобработка данных и PCA** — разведочный анализ данных, обработка выбросов, метод главных компонент, t-SNE визуализация (датасет `BMW Pricing Challenge`).

6. **Индивидуальное задание: Прогноз цены BMW** — обучение модели GradientBoostingRegressor (R² = 79.4%), тестирование на реальном автомобиле: прогнозная цена (€14 133) близка к реальной (€13 900).

## 🔧 Используемые технологии
- **Python:** pandas, NumPy, scikit-learn, matplotlib
- **Модели:** линейная регрессия, Decision Tree, Random Forest, Gradient Boosting
- **Методы:** PCA, t-SNE, GridSearchCV, проверка статистических гипотез
